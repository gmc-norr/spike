What sets spike apart

Among the tools in Table 8, only spike

  • makes new reads for every variant type from the sample's own phased copy of the region, so nearby SNPs travel with the event and a het deletion leaves the SNPs inside homozygous
  • learns the qualities and errors of those reads from the input itself, at start-up, with no separate training step; the other tools that make new reads give every base one quality or use a profile prepared beforehand
  • returns the whole real sample as FASTQ, so the full clinical pipeline (alignment, duplicate marking, calling) runs from the first step

Also built in

  • spike validate measures each planted event; events that cannot be planted faithfully are refused (Table 3)
  • Events by gene and exon name: del:LDLR:exon4-exon8

Where other tools go further

  • Long and linked reads; STR expansions (VISOR)
  • Tumour designs: purity, clones, somatic sets (BAMSurgeon, VarSim, VISOR, SVEngine)
  • Each read's true origin (NEAT's golden BAM; VarSim's read names)
  • No sample needed: any genome at any depth (NEAT, VarSim, VISOR, SVEngine)
  • Ion Torrent data (VarBen)
  • For an SNV, the existing reads edited in place, keeping their real qualities (SomatoSim, VarBen, BAMSurgeon)

spike · Discussion · 24 / 27

spike's place: it starts from a real sample like the spike-in tools, but makes new reads like the simulators, and learns them from that sample. Why it matters: an independent comparison of read simulators against real data (Milhaven and Pfeifer, Heredity 2023) found the quality scores of wgsim, which BAMSurgeon, SVEngine and VISOR use for new reads, a poor representation of the empirical data. "Phased" is the difference from BAMSurgeon 1.4.1, which assembled its structural-variant templates from the sample's reads and leaves phasing to the user ("we suggest phasing BAMs beforehand"); its 2026 rewrite builds them from the reference, carrying no small variants. The right column is the honest other side: for long reads, tumour designs, a per-read golden truth, or data without any real sample, other tools are the better choice. For a single SNV, editing the existing reads in place keeps them exactly; spike remakes the reads around it instead.
