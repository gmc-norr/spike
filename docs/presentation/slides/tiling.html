Number of synthetic fragments

n = round( C · f · S / L )

C: fragment depth of the donor pool in a 2 kb window at the first breakpoint

f: requested allele fraction

S: usable start positions, haplotype length minus L, minus starts wholly inside new sequence

L: mean fragment length of the pool

The count gives the event the depth that the removed reads had: C · f on average across the haplotype. Additive events (fusions, junction-model duplications) keep every original read and add n = C · f / (1 − f) per breakpoint, f ≤ 0.95. One depth C scales the whole event; the largest local departure from it is recorded as SIM_DEPTH_FOLD.
