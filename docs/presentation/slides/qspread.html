Panels A and B: at each cycle the standard deviation of base quality across reads is the same for real and spike's reads, about 3.5 at the start rising to 6 or 7 at the end. Panel C asks how much quality varies from one read to the next. Real reads differ a lot: about one in eighteen is a perfect read, Q37 at every base, and one in twelve has a mean below Q33. spike's reads now do the same, because the context model keeps each read's class and recent lows. The old first-order chain gave an SD of 0.52 here; a chain fitted directly to the real reads gives 0.55, and real qualities shuffled between reads 0.47, so a one-base memory cannot produce this spread.
