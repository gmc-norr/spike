Workflow of one run

Step 1

Extract donor reads

Pairs within ±10 kb, MAPQ ≥ 20, properly paired

Step 2

Estimate the library model

Fragment lengths, qualities, names, het SNPs

Step 3

Build the variant haplotype

Reference segments in a new order

Step 4

Remove original reads

By copy of origin, at a rate set by the fraction

Step 5

Tile synthetic fragments

Uniform starts, count set by local depth

Step 6

Generate reads, write truth

Qualities, errors, names; FASTQ and VCF

Figure 2. Steps 1–2 read the sample; steps 3–5 modify it; step 6 writes the result. All random draws come from one generator seeded by --seed (default 42), so a given seed gives the same output at any --threads.

Defaults: read window ±10 kb (--flank), MAPQ ≥ 20 (--min-mapq), allele fraction 0.5, haplotype flank 2 kb.
