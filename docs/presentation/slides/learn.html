Before spike changes anything it reads the sample around the event and estimates everything it will need: the insert-size distribution, and once per run a quality and error model from a sample of the whole input, whether the library was adapter-trimmed, the shape of read names, and the sample's heterozygous SNPs, which tell it which of the two copies each fragment came from. In this run 32 fragments could be assigned; 16 more were ties and stay unassigned.
