Dark orange bars mark junctions absent from the reference: a read spanning one aligns as a split read, its pair as a discordant pair, with no type-specific breakpoint code. In a duplication only the span-to-span junction is new. A fusion joins segments of two genes the same way.

spike · Methods · 7 / 25

spike never edits a read in place. It writes the variant as a new sequence built from reference segments, in a new order, reverse-complemented, or with new bases between them, and tiles reads across it. Structural-variant evidence such as split reads and discordant pairs then arises from the aligner, as it does for real reads.
