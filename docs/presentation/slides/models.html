spike · Methods · 5 / 25

This table is the statistical core of spike. Where a model is estimated, it is estimated from the donor pool, the sample's own reads around the event, and it is non-parametric: spike draws from observed values rather than fitting, say, a normal fragment-length distribution. The quality model is a first-order Markov chain, described on slide 10.
