Base quality model: contexts learned from the input

Each base's quality is drawn from the qualities that sampled reads show in the same context:

  • History: the read's last 5 qualities
  • Position: cycles left to the 3′ end, 8 bins
  • Read class: 8 classes of mean quality, drawn per pair
  • Lows: qualities below Q15 among the last 16
  • Run: the longest one-letter run in the template so far

Learned once per run from 20 blocks of 50 kb of the input, per mate. A context is used once it holds 20 observations, else the draw backs off in five steps to the whole mate. Example run: 142,458 pairs, 36,986 full contexts.

The first-order chain this replaced forgot a read's state within a few bases, so all its reads were average. The context model keeps what makes a read good or bad: its class, how many of its recent qualities were low, and whether its template held a long run of one letter, which on Illumina sets off a lasting crash on the strand that reads into it. All of it is learned once per run from 20 blocks of 50 kb spread over the input, because the reads around one event are too few to hold the rare poor reads. Figure 5 shows the run effect in real data: after 12 or more of one letter, 15 percent of real reads crash, against half a percent with no run, and spike's reads follow.
