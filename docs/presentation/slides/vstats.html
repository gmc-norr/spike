Allele-fraction test in spike validate

Model. X ~ Bin(n, p), n = voting fragments (one vote per pair; mates that disagree abstain), p = f(1 − 0.01) + (1 − f)·0.001

Error floor. kmin = smallest k ≥ 3 with P(X ≥ k | Bin(n, 0.001)) < 0.005: more alt reads than errors explain

Power. If P(X ≥ kmin | Bin(n, p)) < 0.99, the site is reported "too shallow", not graded

Pass. x ≥ kmin and x inside the central 99% of Bin(n, p); lower tail only when f = 1

spike validate grades a small variant with a binomial test. It first asks whether the depth is enough to tell the variant from sequencing errors at all; if not, it says too shallow instead of passing or failing on noise. Otherwise the measured alt count must exceed what errors explain and fall within the central 99 percent of the binomial distribution expected for the requested fraction, allowing for a little error in both directions.
