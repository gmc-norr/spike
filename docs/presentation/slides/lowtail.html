This is where the Markov chain falls short. About one real read in a hundred ends in a long run of low-quality bases, a crash; in spike's reads the run length falls off geometrically, as a first-order chain implies, and crashes almost never occur. Aligners soft-clip such ends, so spike's reads are clipped less often than real ones. A fix that copies whole quality strings from real reads restored the crash rate on the hospital BAM, but real crashed ends also carry far more errors than their qualities say, so clipping did not follow; that change is kept on a separate branch.
