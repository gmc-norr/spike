About one real read in a hundred ends in a long run of low-quality bases, a crash, and aligners soft-clip such ends. The old first-order chain made almost none: its run length fell off geometrically. The context model makes them at nearly the real rate, 0.88 against 1.16 percent, because it remembers how many recent qualities were low and whether the read's template held a long one-letter run. Its error table, learned from the sample's own crashed tails, makes those ends err as real ones do, so they are clipped too: on 125,000 held-out reads spike's bad-end clips were 1.23 to 1.27 percent against the sample's 1.26.
