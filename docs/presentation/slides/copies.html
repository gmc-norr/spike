spike · Methods · 8 / 25

Removing reads at random would leave both alleles of every heterozygous SNP inside a deletion, which no real carrier shows. spike instead removes reads by copy. Each original pair inside the event's footprint is removed with a probability that depends on which copy it came from. Averaged over both copies the share removed equals the requested fraction, but at f equals 0.5 the event copy loses all its reads and the other copy keeps all of its own.
