spike: planting known variants into real sequencing data

A read-level simulator for validating variant callers on a laboratory's own samples

[Presenter], [Affiliation]

October 2026 · Source code: github.com/gmc-norr/spike

spike edits only the reads around a variant you name in a real sample, so a caller can be tested on data with the sample's own depth, errors and library. This talk covers how it works, the statistical models behind it, and measurements from real runs.
