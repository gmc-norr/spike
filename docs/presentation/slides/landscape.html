spike · Discussion · 23 / 27

Two families of tools. Spike-in tools start from a real sample: SomatoSim and VarBen edit the bases of existing reads, BAMSurgeon does that for small variants and simulates new reads for structural variants. Reference simulators build a genome and make every read from scratch. spike sits in the first family but makes new reads, like the second, and learns them from the sample. Every cell was checked against the tool's own paper, documentation or code. Two corrections came out of that: BAMSurgeon's structural-variant reads come from wgsim, which gives every base one quality, and NEAT's code supports only SNVs and indels, although its README lists more. ART, the read simulator inside VarSim, uses built-in empirical profiles.
